# Neural Network Experiments

## Overview

A collection of experiments exploring neural networks
and supervised learning tasks using Python.

## Experiments

- Binary-to-decimal number conversion using a neural network.
- Volkswagen Polo price prediction using regression.
- Handwritten digit recognition using the MNIST dataset.

## Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib

## How to Run

Open the Jupyter Notebook and execute the cells sequentially.
