# Machine Learning and Deep Learning Coursework

A collection of machine learning and deep learning projects
developed using Python as part of my academic coursework.

## Projects

### 1. College Admission Classification
Classification experiment using K-Nearest Neighbors (KNN)
to predict college admission outcomes.

### 2. Clustering Algorithms Comparison
Implementation and comparison of multiple clustering
algorithms using Scikit-learn.

### 3. Neural Network Experiments
Experiments with neural networks, regression and
image classification using TensorFlow and Keras.

### 4. Fashion-MNIST CNN Classifier
A Convolutional Neural Network trained to classify
fashion product images using the Fashion-MNIST dataset.
