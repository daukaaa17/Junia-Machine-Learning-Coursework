# Comparative Analysis of Clustering Algorithms

## Overview

This project explores and compares different unsupervised
machine learning algorithms using Python and Scikit-learn.

The goal is to investigate how different clustering
approaches group data points and compare their
computational performance.

## Algorithms

- MiniBatch K-Means
- Affinity Propagation
- Mean Shift
- Spectral Clustering
- Agglomerative Clustering
- DBSCAN
- OPTICS
- BIRCH
- Gaussian Mixture Models

## Technologies

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Methodology

- Standardized input features using StandardScaler.
- Constructed a nearest-neighbor connectivity matrix.
- Applied multiple clustering algorithms.
- Visualized clustering results.
- Compared algorithm execution times.

## How to Run

Open the Jupyter Notebook and run the cells sequentially.
