# College Admission Classification

## Overview

This project explores a classification task using
college admission data.

The objective is to apply machine learning techniques
to predict admission outcomes.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Methodology

- Loaded and explored the dataset.
- Prepared the input features.
- Applied the K-Nearest Neighbors (KNN) algorithm.
- Evaluated and visualized classification results.

## How to Run

Open the Jupyter Notebook and execute the cells sequentially.

## Files

- college-admission-classification.ipynb
