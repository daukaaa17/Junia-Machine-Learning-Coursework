# Fashion-MNIST Image Classification with CNN

## Overview

This project implements a Convolutional Neural Network
(CNN) to classify clothing images from the Fashion-MNIST
dataset.

The dataset contains 70,000 grayscale images across
10 clothing categories.

## Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Model Architecture

The CNN uses the following layers and techniques:

- Conv2D
- MaxPooling2D
- Dropout
- Dense layers

## Results

The model achieved 91.74% accuracy during evaluation
in the original notebook.

Note: The original notebook uses the test dataset
for validation during training as well as final evaluation.
This result should therefore be treated as an experimental
result rather than an independent test score.

## How to Run

Open the Jupyter Notebook and execute the cells sequentially.
